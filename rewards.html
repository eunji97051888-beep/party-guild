문파 재화 · 보상 관리

매주 월~일 출석 기준으로 지급 우선순위를 살펴보고, 실제 상점 구매와 지급 내역을 관리해.

이 장부는 지금 사용하는 브라우저에만 저장돼. 누구나 페이지 주소로 들어올 수 있지만 다른 사람의 브라우저에는 네 데이터가 없어. 공용 PC에서는 사용하지 말고, JSON 백업 파일은 GitHub 공개 저장소에 올리지 마. 게임 내 구매·지급은 자동 실행되지 않아.

백업 · 복구 · 테스트 기록 정리

준비 중

초기화는 이 브라우저의 보상 장부 전체만 삭제해. 실제 운영 기록이 있다면 절대 누르지 말고, 먼저 보상 장부 JSON을 백업해. 출석 기록은 기존 출석 관리 페이지의 JSON 백업으로 따로 보관해 줘.
