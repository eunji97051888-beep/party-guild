③ 게임 주간 스크린샷 교체 (선택)

새 사진이 있을 때만 교체해. JPG/PNG를 선택하고 아래 새 스크린샷 다운로드를 눌러 weekly.png를 받아. 이 이미지 파일을 GitHub에 따로 업로드해야 실제 홈페이지 사진이 바뀌어. data.js만 업로드하면 사진은 그대로야.

④ 수정한 일정 파일 저장하기

저장이 되지 않으면 이 단락 아래에 표시되는 오류 메시지를 확인해 줘. 모든 자료실·유튜브 입력란에 올바른 제목과 주소가 필요해.

한 번에 ZIP 다운로드를 누르면 data.js가 포함되고, 새 주간 플래너를 선택했다면 weekly.png도 포함돼. 기존 개별 다운로드 버튼도 사용할 수 있어. 아래 버튼을 눌러 data.js 파일을 다운로드해. GitHub 백업용으로 공지사항, 자료실, 유튜브 영상, 요일별 일정, 문파 안내 문구를 한 번에 저장해. 공지사항만 수정했어도 이 파일을 다시 업로드하면 돼.

⑤ GitHub에 반영하기

1. 위에서 data.js를 다운로드해.
2. 스크린샷을 바꿨다면 새 스크린샷 다운로드로 받은 weekly.png도 다운로드해. 이 파일을 반드시 GitHub에 업로드해야 사진이 바뀌어!
3. GitHub의 party-guild 저장소를 열어.
4. Add file → Upload files에서 받은 파일을 올려. 같은 이름의 기존 파일은 교체돼.
5. Commit changes를 누르고 잠시 기다려.
6. 문파 웹사이트를 새로고침해서 변경을 확인해.

※ GitHub 계정 로그인은 GitHub에서만 진행해. 이 편집기는 비밀번호를 수집하지 않아.
