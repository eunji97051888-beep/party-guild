GUILD MASTER TOOLS

문주 전용 일정 편집기

완전 무료 방식 — 이 편집기는 컴퓨터에서 자료를 수정하고 새 파일을 내려받는 도구야. 수정 내용은 직접 GitHub에 올려야 문파원에게 보여. 별도 비밀번호나 데이터베이스가 없으므로 이 편집기 주소 자체는 비밀 관리자 페이지가 아니야.

① 문파 안내 수정

② 요일별 일정 수정

하나의 일정에서 여러 요일을 체크할 수 있어. 예: 산신 산군대호는 월·수·금.

공지사항 추가 · 수정 · 삭제

제목과 내용 입력 후 공지사항을 추가해. 등록된 공지도 여기에서 바로 고치거나 삭제할 수 있어. 위쪽 고정에 체크하면 공지 목록 맨 위에 보여.

자료실 링크 관리

공략 사이트, 문파 자료 등을 추가·수정·삭제해. 주소는 https:// 로 시작해야 해.

유튜브 영상 관리

유튜브 영상 주소와 표시 제목을 넣어. 일반 영상, Shorts, youtu.be 링크 모두 지원해.

③ 게임 주간 스크린샷 교체 (선택)

새 사진이 있을 때만 교체해. JPG/PNG를 선택하면 업로드용 weekly.png로 변환해 내려받을 수 있어.

④ 수정한 일정 파일 저장하기

저장이 되지 않으면 이 단락 아래에 표시되는 오류 메시지를 확인해 줘. 모든 자료실·유튜브 입력란에 올바른 제목과 주소가 필요해.

아래 버튼을 눌러 data.js 파일을 다운로드해. 공지사항, 자료실, 유튜브 영상, 요일별 일정, 문파 안내 문구를 한 번에 저장해. 공지사항만 수정했어도 이 파일을 다시 업로드하면 돼.

⑤ GitHub에 반영하기

1. 위에서 data.js를 다운로드해.
2. 스크린샷도 바꿨다면 weekly.png도 다운로드해.
3. GitHub의 party-guild 저장소를 열어.
4. Add file → Upload files에서 받은 파일을 올려. 같은 이름의 기존 파일은 교체돼.
5. Commit changes를 누르고 잠시 기다려.
6. 문파 웹사이트를 새로고침해서 변경을 확인해.

※ GitHub 계정 로그인은 GitHub에서만 진행해. 이 편집기는 비밀번호를 수집하지 않아.
