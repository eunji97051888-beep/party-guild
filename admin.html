문주 GitHub 운영 편집기

GitHub 전용 관리 방식 · 공지, 안내, 일정, 유튜브, 자료실을 수정한 뒤 아래 「data.js 다운로드」 버튼으로 파일을 받아 GitHub에 올려줘. 이 페이지는 로그인 없이 열리므로, 개인정보나 비밀 정보는 입력하지 마.

① 문파 안내 수정

② 요일별 일정 수정

하나의 일정에서 여러 요일을 체크할 수 있어. 예: 산신 산군대호는 월·수·금.

공지사항 추가 · 수정 · 삭제

제목과 내용 입력 후 공지사항을 추가해. 등록된 공지도 여기에서 바로 고치거나 삭제할 수 있어. 위쪽 고정에 체크하면 공지 목록 맨 위에 보여.

자료실 링크 관리

공략 사이트, 문파 자료 등을 추가·수정·삭제해. 주소는 https:// 로 시작해야 해.

유튜브 영상 관리

유튜브 영상 주소와 표시 제목을 넣어. 일반 영상, Shorts, youtu.be 링크 모두 지원해.

📅 문파 주간 플래너 직접 편집 (GitHub 저장)

게임사 스크린샷 대신 표시하는 문파 전용 일정판이야. Firebase 정지 중에도 쓸 수 있어.

⚔ 플래너 편집기 열기 ↗

일정 수정 후 편집기에서 weekly-board-data.js를 내려받아 GitHub에 올려줘.

④ 변경 내용 GitHub에 저장하기

저장이 되지 않으면 이 단락 아래에 표시되는 오류 메시지를 확인해 줘. 모든 자료실·유튜브 입력란에 올바른 제목과 주소가 필요해.

공지·안내·요일별 일정·자료실·유튜브를 모두 수정한 뒤 data.js를 다운로드하고 GitHub에 업로드해. 주간 달력은 별도 플래너 편집기에서 weekly-board-data.js를 받아 올리면 돼.

⑤ GitHub에 반영하기

1. 위쪽 내용을 수정하고 data.js 다운로드 → 2. GitHub party-guild 저장소에서 Add file → Upload files → 3. 같은 이름의 data.js 업로드 → 4. Commit changes → 5. 홈페이지 새로고침. 주간 달력은 별도 편집기에서 weekly-board-data.js를 받아 동일하게 업로드.

※ GitHub 계정 로그인은 GitHub에서만 진행해. 이 편집기는 비밀번호를 수집하지 않아.

📜 예치님 요약 보고서 관리

여러 장을 등록하고 제목을 수정하거나 순서를 바꿀 수 있어. 한 페이지에 4장씩 표시돼. 마지막에 ‘게시 파일 다운로드’를 눌러 GitHub에 업로드해야 다른 문파원에게도 반영돼.

업로드 전에 기존 게시글 목록과 순서를 확인해 줘.

업로드 파일은 yechi-report-data.js 단 하나야. 공개 GitHub에 게시되므로 사진에 개인정보가 없는지 확인해 줘. 자동 클라우드 저장은 지원하지 않아.
