🔗 설문 바로가기 링크 관리

문파 홈페이지 상단의 큰 설문 버튼 두 개에 연결할 구글 설문지 주소를 등록하는 도구야. 공용 응답자 링크만 입력해. 관리용 스프레드시트 주소나 개인 응답 수정 주소는 넣지 마.

연결할 설문지 주소

링크 둘 다 입력하는 것을 권장해. URL이 비어 있으면 버튼은 '링크 등록 대기' 상태로 표시돼.

GitHub에 적용하는 방법

  1. 구글 설문지에서 각각 '응답자 링크 복사'를 눌러 위 칸에 붙여넣어.
  2. survey-links.js 다운로드를 눌러 파일을 받아.
  3. GitHub party-guild 저장소 맨 위에 같은 이름의 survey-links.js를 업로드하고 Commit changes.
  4. 홈페이지에서 새로고침하면 버튼 두 개가 실제 설문 링크로 연결돼.

이 페이지는 파일을 내려받는 편집기일 뿐, 자동으로 GitHub에 저장하지 않아.
