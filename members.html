🎲 행운의전당 · 추첨 명단 내보내기

출석 기록을 기준으로 참석 횟수만큼 추첨권을 부여하는 추첨기용 JSON 명단을 만들 수 있어. 탈퇴 문파원과 참석 0회 문파원은 자동 제외돼.

🔒 2026년 10월 28일 분배는 이미 마감한 것으로 보고, 다음 정산(2026년 11월)은 10월 29일부터 집계하도록 기본값을 잡았어. 10월 30일·31일 출석은 다음 분배에 포함돼. 종료일은 실제 다음 분배 마감 회차에 맞춰 변경해 줘. 다음 정산 월을 처음 선택하면 앞선 정산 종료일의 다음 날부터 자동 제안해.

추첨 대상 인원을 계산하고 있어.

※ 전체 콘텐츠를 선택해도 집계 시작일~종료일에 해당하는 회차만 집계해. 다운로드한 JSON은 정산 월·기간·회차 ID를 함께 기록해. 날짜가 겹치지 않는지 확인한 뒤 추첨기에서 명단 불러오기를 눌러 줘.

※ 현재 출석 장부는 이 브라우저에 저장돼. 다른 PC에서 열면 명단이 없을 수 있으니 출석 관리에 사용하던 브라우저에서 열어 줘.

문파 콘텐츠 · 회차 관리

전체 0회차

콘텐츠별 누적 회차를 자동 표시하고, 시작 시간과 특이사항은 따로 관리해. 회차 번호는 삭제 후에도 바뀌지 않아.

＋ 새 회차 등록

회차는 콘텐츠별로 자동 제안돼. 필요할 때 직접 수정할 수 있고, 시작 시간과 메모는 비워둬도 돼.

등록된 회차

콘텐츠를 눌러 목록을 걸러 봐. 회차를 수정해도 출석 기록은 유지돼.

⚠ 회차를 삭제하면 해당 출석 기록도 함께 삭제돼. 수정은 안전하지만 삭제 전에는 JSON 백업을 추천해.

SUMMARY

문파원별 출석 통계

문파원가입일참석불참제외미입력가입 전참석/기록출석률

출석률 = 참석 ÷ (참석 + 불참) × 100. 기존 문파원은 가입일 미확인으로 유지할 수 있어. 신규 문파원은 가입일이 자동 기록되고 가입 전 회차는 분리돼. 미입력은 출석률 계산에서 제외돼. V12 보상 분배 기능은 여기서 보존한 고유 문파원 ID를 활용할 예정이야.
