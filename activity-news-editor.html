이미지는 자동 축소·압축해서 JS 파일에 포함해. 기존 글을 수정할 때 사진을 새로 선택하지 않으면 그대로 유지돼.

GitHub에 게시하기

아래 버튼으로 내려받은 파일을 GitHub 저장소 맨 위에 올린 후 Commit changes를 누르면 돼. 편집기에서 '글 저장'만 누르는 건 공개 게시가 아니야.

주의: 방문자에게 공개되는 파일이므로 닉네임 등 민감한 개인정보가 담긴 스크린샷은 주의해서 선택해 줘. 글이 많고 사진이 많으면 사이트 용량이 늘 수 있어.
