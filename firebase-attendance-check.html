Firebase 출석 연결 점검

현재 홈페이지·문주편집기·Firestore 데이터는 변경하지 않고 최신 출석 백업과 과거 클라우드 백업을 읽어서 비교하는 독립 시험 페이지야.

🔒 읽기 전용 · 저장, 복원, 삭제, 추첨 실행 기능은 없어. 테스트가 끝나기 전에는 문주편집기의 클라우드 복원/덮어쓰기를 누르지 마. 이 페이지는 Google 계정 인증 후 관리자에게 허용된 Firestore 문서 한 개만 읽어.

① 최신 출석 JSON 불러오기

PC에 저장해 둔 party-attendance-2026-11-03(1).json 파일을 선택해. 파일은 브라우저 메모리에서만 분석하며 Firebase로 전송하지 않아.

아직 선택하지 않았어.

② Firebase의 예전 백업 읽기

예전에 사용하던 guildPrivate/attendanceBackup 문서 한 개만 읽어. 백업 문서가 없으면 없는 그대로 알려줄게.

아직 Firebase에 접속하지 않았어.

③ 차이점 확인

두 자료를 모두 읽으면 회원 고유 ID, 회차 ID, 출석 상태와 직접·오토 구분을 비교해. 결과는 개수만 표시해서 문파원 명단을 노출하지 않아.

최신 JSON과 Firebase 데이터를 각각 읽은 후 비교할 수 있어.


이 파일들은 정상 운영 중인 index.html / members.html / attendance-view.html을 수정하지 않아. Firebase 연결을 영구적으로 복구하는 작업은 이번 비교 결과를 확인한 뒤 별도의 복사본에서 진행해.
