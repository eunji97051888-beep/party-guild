복원 전 꼭 확인해 줘

이전 상태로 복원하면 선택한 장부의 현재 전체 기록이 교체돼. 실제 게임의 재료 지급을 취소하거나 Firebase 데이터를 자동으로 바꾸지는 않아.

복원 직전 현재 기록도 이력에 백업한 다음 교체하도록 만들었지만, 브라우저 데이터 삭제에 대비해서 위의 현재 기록 JSON 백업도 별도로 받아두는 게 좋아.
