주간 일정 편집

드래그 배치 (월~일 · 기본 8줄)

일정 카드를 클릭하면 위치 설정이 나타나요.

적용 방법

1. 위에서 내용을 바꾸거나 카드를 드래그한 다음 플래너 파일 다운로드를 눌러.
2. GitHub → party-guild → Add file → Upload files.
3. 다운로드한 weekly-board-data.js만 업로드하고 Commit changes.
4. 홈페이지를 새로고침하면 반영돼.

주의: 현재 이 편집기는 비밀번호가 없는 정적 페이지야. 다른 사람도 편집기 화면은 열 수 있지만 GitHub에 올릴 권한이 없다면 공개 홈페이지를 바꾸지는 못해.
