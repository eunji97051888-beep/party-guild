⚖ 공정한 재료 분배 추천

선택한 기간의 출석과 실제 지급 완료 기록을 비교해 참고 순위를 보여줘. 추천만 하며 재화를 차감하거나 지급 상태를 변경하지 않아.

분배 참고 순위

순위 기준: 참석 횟수가 많은 순 → 같은 참석 횟수라면 기간 내 지급 완료 횟수가 적은 순 → 출석률 높은 순. 실제 아이템 종류·수량·기여도 차이는 자동으로 점수화하지 않아. 제외·미입력은 출석률 계산에서 빼고, 기록이 전혀 없는 문파원에게는 추천 순위를 매기지 않아.

운영 시 유의사항

지급 완료 횟수는 보상 장부에 기록된 지급 건수를 뜻해. 지급된 아이템의 가치나 수량이 같다는 뜻은 아니야. 출석 기록을 아직 입력하지 않은 문파원이 불이익을 받지 않도록 반드시 원본 기록과 실제 기여도를 확인해 줘.

이 페이지는 현재 브라우저의 데이터를 읽기만 해. Firebase 백업을 자동으로 불러오거나 업로드하지 않으며, 출석·보상 장부를 절대 수정하지 않아.
