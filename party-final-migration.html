🏆 보상 · 당첨 · 킵 기록 통합 이전

③ 이후 운영

최초 등록 후에는 재화·보상 관리에서 서버 장부를 수정하고, 행운의전당 결과 편집기에서 새 당첨 결과를 게시해. 킵 잔액 관리에서는 최신 장부를 확인하고 게시해.

문파원 공개 확인: 🏆 행운의전당 · 출석 게시판

이 페이지는 GitHub 코드나 다른 Firebase 운영 문서를 수정하지 않아. 서버 문서는 관리자 보안 규칙으로 제한되어야 하며, 저장 전후 서버 재조회 검증을 수행해. 사용 중인 다른 브라우저에서의 미저장 기록은 자동으로 찾아낼 수 없어.
